# Image Downloader

Расширение для Chrome, которое позволяет скачивать все изображения с веб-страницы.

## Возможности

- Скачивание всех изображений с веб-страницы
- Выборочное скачивание изображений
- Скачивание в архиве или по отдельности
- Поддержка различных форматов изображений

## Технологии

- React
- TypeScript
- Material UI
- Vite
- Chrome Extension API
- Sentry для мониторинга ошибок

## Разработка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Создание архива для публикации
npm run zip
```

## Установка

1. Соберите расширение с помощью `npm run build`
2. Откройте Chrome и перейдите на страницу `chrome://extensions/`
3. Включите режим разработчика
4. Нажмите "Загрузить распакованное расширение" и выберите папку `build`
